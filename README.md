# STACWARS: [Nova]

## Project Overview
This repository contains the final submissions for the STACWARS hackathon. It encompasses three distinct Problem statements , cleanly separated into dedicated directories.

## Tasks Attempted
*   PS1: explains the design approach and thought process, the Mustafar launch conditions, the recovery system, and the Earth-versus-Mustafar comparison. It gives a prediction and result for each environmental change (gravity, pressure, temperature, air density and wind) 
*   PS2: Solar Prediction Analysis: Cleaned environmental sensor data, extracted temporal insights regarding solar flares, and built a Random Forest Regressor (R²: 0.91) to predict radiation based on temperature and time.


## Repository Structure
* `PS1_[Rocket]`: contains Nova_Rocket.ork,Nova_FlightData.csv,Nova_Report.pdf
* `PS2_[Data analytics]`: Contains the Jupyter Notebook (`solar_prediction_analysis.ipynb`) and the raw dataset (`SolarPrediction.csv`)and report.pdf('PS2 Data analysis.pdf').
